# LMT Canva Design Library
**Last updated:** 2026-08-11

All Canva design briefs, specs, and exported files live here.
For brand colors, fonts, and voice — see `../brand-constants.md`

---

## Folder Structure

| Folder | What Goes Here |
|---|---|
| `flyers/` | Event flyers, program one-pagers, grant flyers |
| `social/` | LinkedIn posts, Facebook graphics, IG posts |
| `presentations/` | Pitch decks, workshop slides, speaking decks |
| `video-thumbnails/` | YouTube thumbnails, podcast covers |
| `exports/` | Final PDF/PNG exports ready to send or publish |
