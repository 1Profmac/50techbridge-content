# ============================================
# HOW TO ADD IN REDIRECTION PLUGIN:
# ============================================
#
# OPTION A — Add one by one (tedious but precise):
#   1. Tools → Redirection
#   2. Click "Add New"
#   3. Source URL: paste the left side (e.g., /online-sales-strategy/(.*) )
#   4. Check "Regex" box for any rule with (.*)
#   5. Target URL: paste the right side (e.g., /courses/)
#   6. Click "Add Redirect"
#   7. Repeat for each rule
#
# OPTION B — Import CSV (faster):
#   1. Tools → Redirection → Import/Export tab
#   2. Upload the CSV file (see below)
#
# OPTION C — Add to .htaccess directly (fastest, advanced):
#   1. Go to Tools → Redirection → Site tab
#   2. Or edit .htaccess via Bluehost File Manager
#   3. Paste the Apache rules below
