# Weekly Site Maintenance Checklist
## Run every Monday morning — 15 minutes
## Tell Claude: "run weekly site check"

---

## 1. GOOGLE INDEXING CHECK (2 min)
- [ ] Search `site:learnmoretechnologies.com` in Google
- [ ] Count indexed pages — should be growing, not shrinking
- [ ] Check if key pages are indexed: /join-now/, /workforce/, /courses/
- [ ] Check for pages that shouldn't be indexed (/test/, draft pages)

## 2. LANDING PAGE STATUS (3 min)
- [ ] Visit learnmoretechnologies.com/join-now/ — does it load with real content?
- [ ] Visit learnmoretechnologies.com/workforce/ — does it load with real content?
- [ ] Visit learnmoretechnologies.com/courses/ — are courses visible?

## 3. GOOGLE SEARCH CONSOLE (3 min)
- [ ] Log into search.google.com/search-console
- [ ] Check for crawl errors
- [ ] Check for mobile usability issues

- [ ] Submit any new pages for indexing

## 4. CONTENT STATUS (3 min)

## GOOGLE SEARCH CONSOLE SETUP

If not already set up:
1. Go to search.google.com/search-console
2. Add property: learnmoretechnologies.com
3. Verify ownership (DNS, HTML tag, or Google Analytics)
4. Submit sitemap: learnmoretechnologies.com/sitemap.xml
5. Request indexing for /join-now/ and /workforce/

This is how you tell Google "these pages exist, crawl them."
Without Search Console, Google finds your pages on its own schedule — could be weeks.
