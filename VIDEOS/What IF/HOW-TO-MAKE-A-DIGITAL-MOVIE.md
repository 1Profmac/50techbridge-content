## The Simple Truth

A digital movie is a Canva slideshow where the slides are video clips instead of images,
and audio runs underneath the whole thing instead of slide by slide.

You already know how to make a slideshow. This is the same skill, bigger canvas.

---

## What Makes It Feel Like a Movie

Four things separate a slideshow from a film:

1. **Moving images** — clips generated by AI (Veo, Galaxy AI) instead of static photos
2. **Continuous audio** — voiceover + music run the full length, not clip by clip
3. **Character voices** — different people speaking at different moments
4. **Editing illusion** — characters appear to interact because their audio tracks are stacked in sequence

None of these require a camera crew. All of them can be done with tools you already own.

## The 10 Production Stages — In Order

### STAGE 1 — SCRIPT (.md, .txt)
Write every word before touching any tool.
- Full scene-by-scene script with voiceover lines
- Character dialogue for every person who speaks
- Timing notes (how many seconds each scene runs)

**Your files:**
- `WHAT-IF-AI-STORY-FILM.md` — 3-episode story script
- `what-if-4min50sec-film.md` — original brand film script
- `CHARACTER-DIALOGUE-SCRIPT.md` — all character lines

### STAGE 2 — CHARACTER REFERENCE IMAGES (.png)
Lock every character's face before generating any video.
If you generate video without a reference image, faces will be inconsistent across scenes.

**How to:**
1. Use Google Gemini or Midjourney to generate a front-facing portrait of each character
2. Save the approved image as `[character-name]-reference.png`
3. Use this image in every Veo prompt for that character

**Your characters:** Marcus, Carol, Dorothy, James, Rosa, Tom Briggs, Dr. Linda Chen

---

### STAGE 3 — AI VIDEO PROMPTS (.md)
Write the Veo/Galaxy AI prompts BEFORE generating.
One prompt per scene. Each prompt = one 8–12 second video clip.

**Prompt structure:**
```
[Character reference] + [Location] + [Lighting] + [Camera movement] + [Emotion] + [Duration]
```

**Example:**
```
Black man 58, dark navy suit, seated at glass table in corporate interview room.
Cold blue-white fluorescent overhead lighting. Posture straight, dignified, ready.
Looking at interviewer who is not looking back. Slow camera push toward background screen
showing "FLAG: DEMOGRAPHIC RISK" in red. 10 seconds. Cinematic. Photorealistic.
```

### STAGE 7 — CREATE CUSTOM VOICES (When Needed)
When no existing ElevenLabs voice fits a character:

**Voice Design (no recording needed):**
1. ElevenLabs → Voices → + Create Voice → Voice Design
2. Describe the character in plain language:
   *"65-year-old African American woman, warm, slightly surprised, conversational,
   not elderly, not frail — genuine and real"*
3. Generate 4–6 options → audition with the character's actual line
4. Save the best one to My Voices with the character's name

**Instant Voice Clone (if you have audio):**
1. ElevenLabs → Voices → + Create Voice → Instant Voice Clone
2. Upload 1–5 minutes of clean audio of the person speaking
3. ElevenLabs clones that voice exactly

**DO NOT USE:** ElevenLabs Agents — that is a live chatbot system, not a film production tool.

### STAGE 10 — ASSEMBLE IN CANVA VIDEO EDITOR
This is the step that turns everything into a film.

**Timeline structure:**
```
VIDEO TRACK:   [clip-01][clip-02][clip-03][title-card][clip-04]...
AUDIO TRACK 1: [brian-voiceover.mp3 — runs full length          ]
AUDIO TRACK 2: [character-voices placed at exact scene moments  ]
AUDIO TRACK 3: [music.mp3 at 15% volume — runs full length      ]
```

**Steps:**
1. Start a new Canva video project — 1920×1080, 16:9
2. Drag video clips onto timeline in script order
3. Trim each clip to the exact duration from your timing sheet
4. Add Brian voiceover as Audio Track 1 — runs the full length
5. Place character voice MP3s at the correct timestamps
6. Add music as Audio Track 3 — lower the volume to 15%
7. Add Canva title cards at the right moments
8. Add transitions: **Cross-fade only** — 0.5 seconds between clips
9. Auto-Caption → review → correct any errors
10. Export → Download → MP4 → 1080p

## How Characters Appear to Talk to Each Other

Characters do not actually interact in real time. It is an editing illusion.

**Example — Marcus and the Interviewer:**
```
Canva timeline:
[0:00–0:10] Marcus clip playing (he's seated, expression ready)
[0:00–0:09] marcus-comeback-interview.mp3 playing on audio track
[0:09–0:10] 1 second of silence
[0:10–0:20] Interviewer clip playing (he leans forward)
[0:10–0:19] interviewer-warm-ep3.mp3 playing on audio track
```

The audience hears a conversation. There was no conversation.
Two audio files. One second gap. That's the whole trick.

## What ElevenLabs Agents Is NOT

ElevenLabs Agents (the templates page with Customer Support, Hotel Reservation, etc.)
is a live AI chatbot system. It is built for businesses that want a voice bot to answer
real calls or chat with real customers in real time.

It cannot:
- Generate scripted film dialogue
- Make characters interact as pre-written scenes
- Produce audio files for editing

**Use Text to Speech for film production. Agents is someone else's product.**

## File Naming Convention

Always name files to match the script. Unnamed files become orphaned and unfindable.

| File Type | Naming Pattern | Example |
|---|---|---|
| B-Roll clips | `clip-[##]-[scene-name].mp4` | `clip-01-the-march.mp4` |
| Character scenes | `clip-[##]-[scene]-[character].mp4` | `clip-02-algorithm-interview-carol.mp4` |

## The Order You Must Follow

```
Script → Characters → Prompts → Video Clips → Voiceover → Music → Title Cards → Assembly → Export
```

You cannot assemble before you have clips.
You cannot sync audio before you have voiceover.
You cannot caption before you have a cut.

Each stage unlocks the next. The script is the foundation.
Everything downstream of a bad script is expensive to fix.
