===================================================================
ELEVENLABS → HEYGEN WORKFLOW (STEP BY STEP)
===================================================================

In ElevenLabs:
  1. Select voice preset for character
  2. Paste script text
  3. Set stability: 65–75 | Similarity: 75–85 | Style: 20–30
  4. Generate → download MP3

In HeyGen:
  1. Go to Avatars → Talking Photo
  2. Upload character PNG (front-facing)
  3. Upload MP3 from ElevenLabs
  4. Select: 16:9 | 1080p | No background change
  5. Generate → download MP4

The MP4 output from HeyGen is your final on-camera character clip.
Drop it directly into the Canva timeline at the correct scene position.
