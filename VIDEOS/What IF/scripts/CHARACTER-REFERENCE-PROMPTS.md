## HOW TO USE THESE PROMPTS

### Step 1 — Generate the Base Reference Sheet
1. Go to Leonardo AI → Image Generation
2. Use the CHARACTER SHEET prompt below for each character
3. This gives you front, side, and 3/4 views in one image
4. Save the output — this is your locked reference image

### Step 2 — Lock the Character for Every Scene
1. In Leonardo AI: click "Add Image Reference" → upload your character sheet
2. Set Character Reference strength to **0.8–1.0**
3. Fix the seed from your base image (copy seed number, paste into new prompts)
4. Use the SCENE PROMPT for each clip

### Step 3 — Consistency Rules
- Always include: `same character as reference, identical facial structure, consistent skin tone`
- Always exclude (negative prompt): `deformed face, extra limbs, inconsistent features, different age`
- Keep lighting description the same within each world (cold blue = machine world / warm gold = human world)

**Name in script:** The Woman / 64-year-old Pioneer
**Appears in:** Scenes 4, 9 (community center), 10 (Pioneer montage)

---

### CHARACTER SHEET PROMPT (Generate First)
```
Character consistency sheet. Black woman, 64 years old, natural beauty 
and quiet confidence. Short natural silver-black hair, close cropped 
or small afro. High cheekbones, warm smile lines around eyes. 
Dark brown eyes, expressive. Medium-brown skin tone, warm undertone. 
Build: medium, grounded posture. Wearing practical professional clothing — 
a jewel-toned blouse (deep teal or burgundy) in human world scenes, 
or a neat blazer in machine world scenes.

Four views on white background: front facing, 3/4 left, profile right, 
close-up face. Photorealistic. Consistent lighting across all views. 
Studio neutral light. High resolution. No background elements.
```

## SEED LOCKING INSTRUCTIONS

After generating your base character sheet:
1. In Leonardo AI → find your generated image
2. Click the image → copy the **Seed Number** shown
3. Paste that seed into every new generation for that character
4. This alone boosts consistency by ~80%

```
deformed face, extra limbs, inconsistent features, different age, 
different skin tone, blurry face, low resolution, cartoon, 
illustration, anime, different hair, disfigured, ugly, bad anatomy
```
