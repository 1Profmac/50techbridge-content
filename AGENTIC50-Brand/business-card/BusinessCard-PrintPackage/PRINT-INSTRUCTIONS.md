## SPOT UV MASK INSTRUCTIONS

The spot UV mask tells the printer exactly which elements get the glossy raised finish.
- **Black areas = glossy spot UV** (gold text, logo stamp, borders, social handles, QR frame)
- **White areas = matte only** (navy background, white text — no gloss)

To create the mask PNGs:
1. Open `SpotUV-MASK-FRONT.html` in Chrome
2. Right-click → Inspect → Device toolbar → set to 2100x1200
3. Screenshot (or use Snagit) → save as `SpotUV-MASK-FRONT-2100x1200.png`
4. Repeat for `SpotUV-MASK-BACK.html`

Or send the HTML files directly to 4over — their prepress team can extract the mask.

## PROOFING CHECKLIST

Before full print run, verify:

- [ ] Navy background is rich and deep — not washed out
- [ ] Gold `#C8942E` reads warm, not yellow or orange
- [ ] White text on navy is crisp and legible
- [ ] QR code scans successfully (test with phone camera)
- [ ] All text is within safe zone (0.125" from trim)
- [ ] Rounded corners match on both sides (if die-cut)
- [ ] Spot UV alignment on gold elements (if premium option)
- [ ] No banding in navy background gradient areas
- [ ] Microphone details are visible (grille lines, yoke)
- [ ] Card reads clearly at arm's length — ADA 16pt minimum text

---

## CORNER RADIUS

The card design has rounded corners (radius ~12pt at print scale). Two options:

1. **Die-cut rounded corners** (preferred) — matches the design exactly
2. **Standard square corners** — the gold inset border already has rounded corners, so square trim still looks intentional

If die-cutting, use 1/8" (3mm) corner radius.
