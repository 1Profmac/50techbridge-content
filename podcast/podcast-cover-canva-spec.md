## CANVA STEP-BY-STEP

1. Open Canva → **Create a design** → **Custom size** → 3000 × 3000 px
2. **Background:** Click background → set color `#0E1C2F`
3. **Radial glow:** Add circle 2400×2400, color `#162640`, opacity 50%, center it, blur edges
4. **Outer ring:** Add circle 2200×2200, border only 8px `#C8942E`, no fill, center
5. **Inner ring:** Add circle 1900×1900, border only 4px `#C8942E`, opacity 50%, no fill, center
6. **Diamonds:** Add 4 squares 40×40, rotate 45°, color `#C8942E`, position at cardinal points on outer ring
7. **Microphone:** Search Canva Elements for "vintage microphone" or "retro mic" → recolor to `#C8942E` → resize to ~600×900 → position center-upper (Y:1000). OR upload the SVG mic from `assets/logos/`
8. **Add text** → `#` → Montserrat Black → 140px → `#C8942E` → center → Y:1550
9. **Add text** → `AGENTIC` → Montserrat Black → 280px → White → letter-spacing 30 → center → Y:1720
10. **Add lines** → two 300px gold rules at Y:1850, flanking center
11. **Add text** → `50` → Montserrat Black → 400px → `#C8942E` → letter-spacing 40 → center → Y:2020 → optional gold glow shadow
12. **Add text** → `THE PIONEERS PODCAST` → DM Sans Medium → 90px → `#C8942E` opacity 60% → center → Y:2280
13. **Add text** → `with Professor Brian McKinney` → DM Sans Regular → 64px → `#C8942E` opacity 50% → center → Y:2420
14. **Add text** → `50+TechBridge · learnmoretechnologies.com/speak` → DM Sans Regular → 48px → `#A8B8CC` → center → Y:2600
15. **Download** → JPG → Quality: Maximum → confirm under 500KB
