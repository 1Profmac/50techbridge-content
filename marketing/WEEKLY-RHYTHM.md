# LMT WEEKLY RHYTHM — Operating Cadence
## Learn More Technologies | Created: April 16, 2026

> **Principle:** Morning Hunt is the non-negotiable daily heartbeat. Everything else bends around it. One heavy production day per week protects energy for revenue-generating human work.

---

## The Split — what runs daily vs what runs 3–4x/week

| Block | Frequency | Duration |
|---|---|---|
| **Morning Hunt** (notifications + 15–20 requests + follow-up DMs) | **Every weekday — non-negotiable** | 25 min |
| **Midday Signal** (3 insight comments + save 1 post) | 3–4x/week on content days | 10 min |
| **Evening Ship** (publish + log + scoreboard) | 3–4x/week on content days | 10 min |

**Why daily on Morning Hunt:** LinkedIn algorithm + buyer pipeline need consistent touch. Skip 2 days and accepts go cold. Morning Hunt is 25 min — not a burden, even on heavy days.

---

## Weekly Schedule

### MON — Content Batch Day
- **25 min** — Morning Hunt
- **2 hrs** — Run content create skill: batch week's LinkedIn posts, schedule them across the week
- **30 min** — Publish 1 article from ready-to-post queue (see CEO-DASHBOARD Content Engine table)
- **Total:** ~3 hrs LinkedIn/content | Rest of day: free for live work (pitches, calls, proposals)

### TUE — Heavy Production Day
- **45 min** — Full 3-block LinkedIn
- **2–4 hrs** — YouTube Short production (fresh build in Canva or green-screen composite — never auto-crop per rule)
- **Total:** up to 5 hrs | Afternoon: rest or short admin

### WED — Phone + Admin Day (revenue priority)
- **25 min** — Morning Hunt
- **60 min** — Phone calls (priority 1 per dashboard: WSCA ETP Coordinator, Goodwill CTX, ACC Continuing Ed, WS Alamo, CMBL Help Desk)
- **60 min** — Applications: STARS Supplier Portal, SCSEP Host Agency, any open RFP responses
- **Rest of day:** flex — caregiving, rest, or follow-up work

### THU — Content Day
- **45 min** — Full 3-block LinkedIn
- **30 min** — Publish Thursday "Overlooked Workforce" series post (per Content Calendar)
- **Rest of day:** Jessica Lemann / warm contact follow-ups, lunch & learn pitch drafting

### FRI — Review + Close Day
- **25 min** — Morning Hunt
- **30 min** — Weekly review + CEO-DASHBOARD scoreboard update
- **15 min** — Git commit: `git add . && git commit -m "Weekly update — [date]"`
- **Rest of day:** flex — calls that moved to Friday, prep for next Monday's batch

### SAT / SUN — Off / Flex
- No mandatory work
- Caregiving, rest, optional backlog, optional content ideation
- Exception: if a Tier 1 target replies and wants a call, take it

## What NOT to do

- Write a new article while the queue has ≥3 unpublished
- Produce a video without naming the specific buyer it's supposed to close
- Auto-crop a landscape video to vertical for Shorts (always fresh build per rule)
- Skip Morning Hunt because "it's a writing day"
- Move phone calls to "later" — they are Priority 1 per dashboard, every week
- Attend an event where your Tier 1 buyer isn't in the room

## Claude CLI trigger phrases for this rhythm

Open Claude Code and type any of these to execute the block:

- **"Morning Claude"** → Daily brief: decisions needed / in-progress / completed / blockers / today's priority queue / pioneer count / message triage / reach building / LinkedIn Morning Hunt walkthrough
- **"Morning todo"** → Builds today's LMT Daily To-Do as a Gmail draft to brian@learnmo.com
- **"Monday batch"** → Content batch walk-through + queue publish
- **"Tuesday production"** → Short topic + buyer confirmation (blocks production if no buyer named)
- **"Wednesday calls"** → Today's call list from dashboard Priority 1 with appropriate pitch script per buyer type
- **"Thursday content"** → Thursday Overlooked Workforce series post walk-through
- **"Friday review"** → Pull weekly metrics, update CEO-DASHBOARD scoreboard, flag blockers, set next week's top 3
- **"Cloud check: [action]"** → Apply CLOUDS vs SIGNAL test to a proposed action; block with signal alternative if it's a cloud
- **"Triage my messages"** → Inbox walk-through with RESPOND / IGNORE / FLAG calls
- **"Article ideas"** → 5 article topics for the week tied to pipeline
- **"Publish queue"** → Ordered list of ready-to-post articles with recommended publish sequence
