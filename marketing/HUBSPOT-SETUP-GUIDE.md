## STEP 2 — Set up your Deal Pipeline (10 min)

This is your sales process. Go to **Settings → Objects → Deals → Pipelines**.

Delete the default stages. Create these 5:

| Stage | What it means | Example |
|-------|--------------|---------|
| **1. Identified** | You found them, no contact yet | TBD names on your target list |
| **2. Connected** | LinkedIn accepted or replied | Jessica Lemann, Dr. Shantana Robinson |
| **3. Meeting Booked** | Calendly or call scheduled | Jessica Lemann (phone this week) |
| **4. Proposal Sent** | They asked for scope/pricing | Black Is Tech (pitch sent Apr 13) |
| **5. Closed Won / Lost** | Done — contract signed or dead | — |

That's it. Five stages. Don't overthink it.

## STEP 5 — Set up your daily view (5 min)

1. **Pin the Deals board** — this is your morning view. Go to Deals → Board view. Bookmark it.

## STEP 7 — Set up your daily routine in HubSpot (5 min)

Go to **Settings → Objects → Activities → Task types**

Create a recurring daily task called **"Morning Pipeline Check"** with this checklist:

```
1. Open Deals board — any deals need a next action?
2. Check "Open" contacts — anyone waiting for follow-up?
3. Log any LinkedIn conversations from yesterday as Notes on the contact
4. Send 5-10 new LinkedIn connection requests (from target list search strings)
5. Move any contacts that progressed to their new stage
```

## THE RULE

Every conversation with a decision maker gets logged in HubSpot. Every. One.
If it's not in HubSpot, it didn't happen. This is how you stop losing follow-ups.
